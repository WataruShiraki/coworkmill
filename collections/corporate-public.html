企業や行政がつくった場所4選

不動産会社だけでなく、メーカーや東京都もコワーキングスペースをつくっています。つくった側の目的が、場所の性格に表れます。

登場する会社

  1. 100BANCH
  2. Tokyo Innovation Base
  3. point 0 marunouchi
  4. ARCH（虎ノ門ヒルズ インキュベーションセンター）

01｜100BANCH（渋谷）

パナソニックの創業100周年を機に開いた実験区

渋谷駅から歩いて5分ほどの3階建てに、100BANCH はあります。パナソニックの創業100周年を機に、2017年7月7日に開いた「100個のプロジェクトがうごめく実験区」です。1階はテストキッチン、2階は35歳未満のプロジェクトが集まるガレージ、3階は100人規模のイベントスペース。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

02｜Tokyo Innovation Base（有楽町）

東京都が運営する「世界中のイノベーションの結節点」

JR有楽町駅の京橋口から歩いて1分、丸の内3-8-3に、東京都が運営する Tokyo Innovation Base（TIB）はあります。「世界中のイノベーションの結節点」を掲げるスタートアップ支援の拠点で、1階のSQUAREやLIVING、2階のSTAGEやFAB、3階のSALONやLOUNGE、別棟のSHOPまで、役目の違う場所が並びます。「多様性をテーマに、ポップでユニークな雰囲気を演出」と公式サイトは説明します。開館は平日10時から21時、土日祝は10時から17時です。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

03｜point 0 marunouchi（丸の内）

ダイキン、オカムラ、パナソニックなど19社が参画

東京駅から歩いて数分、丸ビルの隣の丸の内2丁目ビル4階に、point 0 marunouchi はあります。2019年7月に開いた会員型のコワーキングスペースで、「未来のオフィス空間」を実現するための実証実験の場でもあります。ダイキン、オカムラ、パナソニックなどの企業が参画し、内装のデザインは Klein Dytham architecture が手がけました。2021年1月には、日本のコワーキングオフィスとして初めて WELL認証（WELL v2 pilot）のゴールドランクを取得しています。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

04｜ARCH（虎ノ門ヒルズ インキュベーションセンター）（虎ノ門）

森ビルが企画運営、大企業の新規事業のための施設

虎ノ門ヒルズビジネスタワーの4階に、森ビルが企画運営する ARCH はあります。「世界で初めて大企業の事業改革や新規事業創出をミッションとする組織に特化して構想されたインキュベーションセンター」と公式サイトは説明します。3,800㎡のフロアに、コワーク、個室、プロジェクトルーム、ガラス張りのマグネットルーム、カフェ＆ラウンジが入ります。公式サイトに書かれている内容をもとに、要点をご案内します。
