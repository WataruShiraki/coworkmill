丸の内・有楽町・大手町のコワーキングスペース4選

東京駅のまわりには、東京都、三菱地所、NTT都市開発、大企業の共同体と、つくり手の違う4施設が集まっています。

登場する会社

  1. point 0 marunouchi
  2. Tokyo Innovation Base
  3. 有楽町 SAAI Wonder Working Community
  4. LIFORK 大手町

01｜point 0 marunouchi（丸の内）

丸ビルの隣、大企業19社が共同で運営する実証実験のオフィス

東京駅から歩いて数分、丸ビルの隣の丸の内2丁目ビル4階に、point 0 marunouchi はあります。2019年7月に開いた会員型のコワーキングスペースで、「未来のオフィス空間」を実現するための実証実験の場でもあります。ダイキン、オカムラ、パナソニックなどの企業が参画し、内装のデザインは Klein Dytham architecture が手がけました。2021年1月には、日本のコワーキングオフィスとして初めて WELL認証（WELL v2 pilot）のゴールドランクを取得しています。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

02｜Tokyo Innovation Base（有楽町）

有楽町駅から1分、東京都が運営するスタートアップ支援の拠点

JR有楽町駅の京橋口から歩いて1分、丸の内3-8-3に、東京都が運営する Tokyo Innovation Base（TIB）はあります。「世界中のイノベーションの結節点」を掲げるスタートアップ支援の拠点で、1階のSQUAREやLIVING、2階のSTAGEやFAB、3階のSALONやLOUNGE、別棟のSHOPまで、役目の違う場所が並びます。「多様性をテーマに、ポップでユニークな雰囲気を演出」と公式サイトは説明します。開館は平日10時から21時、土日祝は10時から17時です。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

03｜有楽町 SAAI Wonder Working Community（有楽町）

新東京ビルの3フロア、畳と会員バーのある事業創造コミュニティ

東京駅から近い丸の内の新東京ビルに、三菱地所が運営する SAAI Wonder Working Community はあります。2020年2月に開いた事業創造のコミュニティで、地下1階、1階、4階の3つのフロアを使います。畳の御座敷、六角形のシート、会員専用のバー、ステージ。「多様な人が出逢い、彩りを生みだす場所」と公式サイトは説明します。公式サイトに書かれている内容をもとに、要点をご案内します。

04｜LIFORK 大手町（大手町）

大手町駅直結、4〜30名用のシェアオフィス13タイプ

大手町駅に直結する大手町ファーストスクエア ウエストタワーの1階と2階に、NTT都市開発が運営する LIFORK 大手町はあります。4〜30名用のシェアオフィス13タイプ、時間貸しのスタイルルーム、199.1㎡のレンタルラウンジが入り、シェアオフィスは24時間365日使えます。「上質かつ落ち着いた内装で開放的な空間」と公式サイトは説明します。公式サイトに書かれている内容をもとに、要点をご案内します。
