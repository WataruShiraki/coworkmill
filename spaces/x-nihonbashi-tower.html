日本橋｜コワーキング

X-NIHONBASHI TOWER｜日本橋三井タワー7階、三井不動産が運営する宇宙ビジネスの共創拠点

三越前駅に直結する日本橋三井タワーの7階に、X-NIHONBASHI TOWER はあります。三井不動産が運営する宇宙ビジネス共創拠点「X-NIHONBASHI（クロス・ニホンバシ）」の一つで、307㎡の中にコワーキング、カンファレンス、ミーティングの場所がそろいます。使うには一般社団法人クロスユへの入会が必要です。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

はじめに

宇宙と地上の、新しいイノベーションへ

X-NIHONBASHI は、宇宙ビジネスの拡大と、宇宙と地上の新しいイノベーションの創出を目指して、人々が集まり交流する多彩な舞台です。三井不動産が運営し、日本橋三井タワーの TOWER と、日本橋アイティビルの BASE の2つの施設があります。

TOWER は307㎡の一つの空間を、コワーキング、カンファレンス、ミーティングに使い分けます。シアター形式なら約120席、コワーキングなら約40席、立食なら約150名。使い方に合わせて、同じ部屋の形が変わります。

01｜コワーキング

約40席、平日8時から

コワーキングとして使うときは約40席です。平日の8時から19時まで開いています。

使うには一般社団法人クロスユへの入会が必要です。宇宙ビジネスに関わる人が集まる、目的のはっきりした場所です。

02｜カンファレンス

約120席のシアター形式、約150名の立食

カンファレンスとして使うときは、シアター形式で約120席、立食で約150名が入ります。

宇宙ビジネスの発表や交流会が、コワーキングと同じ部屋で開かれます。働く場所と発表の場所が一つであることが、この施設の特徴です。

03｜もう一つの拠点 BASE

日本橋アイティビルの3・4階

X-NIHONBASHI BASE は、三越前駅から歩いて1分の日本橋アイティビル3階と4階にあります。コワーキング、カンファレンス、バーラウンジ、ミーティング、展示、WEB会議のブース、個人作業のブースがそろいます。

TOWER と BASE の2つの拠点を、日本橋の中で使い分けられます。

クロスユクロスユ

キーワード

クロスユとは

X-NIHONBASHI の施設を使うために入会が必要な一般社団法人です。宇宙ビジネスに関わる会社や人が集まる団体です。

施設を使える人を会員で絞ることで、隣の席の人が同じ分野の人になります。分野を決めたコワーキングの強みです。

編集部より

「宇宙」と分野をはっきり決めたコワーキングは珍しい存在です。分野を絞ると、集まる人の話題がそろいます。日本橋という老舗の街で、いちばん新しい産業を集めている対比も面白いと思います。

307㎡の一つの部屋を、40席の仕事場にも120席の会場にもする。部屋を増やさず、使い方を切り替える設計は、都心の限られた床を生かす方法として参考になります。
