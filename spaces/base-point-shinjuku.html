新宿｜コワーキング

BASE POINT｜新宿駅10分、1階のワーキングカフェから3階のシェアオフィスまで3層のワークスペース

新宿駅から歩いて10分、西新宿7丁目に BASE POINT（ベースポイント）はあります。1階は厳選したコーヒーを楽しみながら働ける時間制のワーキングカフェ、2階は会議室、3階はシェアオフィスです。全日7時から23時まで開いています。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

施設 BASE POINT（ベースポイント） ↗場所 東京都新宿区西新宿7丁目22-3構成 1F ワーキングカフェ／2F 会議室／3F シェアオフィス営業 全日7:00〜23:00（7:00〜10:00、20:00〜23:00は無人）

はじめに

快適な空間とサービスで、仕事に集中する

BASE POINT は、快適な空間とサービスで集中して働くためのワークスペースです。全席に電源、Wi-Fi、フリードリンクがあり、会議室も同じ建物にそろいます。

3つの階で役目を分けています。1階はだれでも入れるワーキングカフェ、2階は会議室、3階は会員のシェアオフィス。入口に近い階ほど開かれ、上に行くほど落ち着く並びです。

01｜1F ワーキングカフェ

22席の時間制カフェ

1階は「厳選されたコーヒーを楽しみながら仕事ができる時間制カフェ」です。寛ぎの場所としても、作業の場所としても使えます。席数は22です。

料金は1時間600円（税込660円）、延長は1分10円（税込11円）、1日の上限は2,700円（税込2,970円）。シェアキッチンのドリンクは自由に使えます。一般の営業は10時から19時です。

02｜2F 会議室

打ち合わせとセミナーの階

2階は会議室です。プロジェクターなどの設備があり、打ち合わせやセミナーに使えます。

カフェで作業をして、そのまま上の階で打ち合わせをする。移動のない使い方ができます。

03｜3F シェアオフィス

会員の仕事場

3階はシェアオフィスです。会員は7時から使え、早朝と夜の時間は無人で運営されています。

新宿駅から少し離れた西新宿7丁目という場所が、駅前の施設とは違う落ち着きを作っています。

ワーキングカフェワーキングカフェ

キーワード

ワーキングカフェとは

カフェのように過ごせて、時間単位の料金で仕事ができる場所です。BASE POINT では1階が22席のワーキングカフェになっています。

会員にならなくても1時間から使えるので、コワーキングの入口として働きます。カフェで気に入った人が、上の階の会員になる流れです。

編集部より

1階をだれでも入れるカフェにする構成は、コワーキングの敷居を下げます。いきなり会員になるより、1時間コーヒーを飲みながら座ってみる。その順番を建物の階で作っています。

朝7時から夜23時までの長い営業を、早朝と夜は無人で回している点も見どころです。人を置く時間と置かない時間を分けることで、小さな施設でも長く開けられます。
