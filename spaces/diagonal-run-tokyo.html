DIAGONAL RUN TOKYO｜京橋MIDビル4階、東京と全国をつなぐコワーキング

都営浅草線の宝町駅から歩いて約1分、京橋MIDビルの4階に DIAGONAL RUN TOKYO はあります。東京と全国各地、そしてヒト、企業（技術）、アイデア、情報が交わる場所を掲げるコワーキングです。フリーデスク、ブース、スモールオフィス、会議室、イベントスペースがそろいます。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

はじめに

東京と全国各地が交わる

DIAGONAL RUN TOKYO が掲げるのは、東京と全国各地、そしてヒト、企業（技術）、アイデア、情報が交わる場所です。名前の「DIAGONAL（斜め）」は、縦と横のつながりを越えて交わることを思わせます。

京橋の京橋MIDビル4階にあり、東京駅にも歩ける距離です。地方から東京に来る人と、東京で働く人が出会う入口になっています。

01｜ドロップインとフリーデスク

1時間から使える

ドロップインは1日3,300円、平日は1時間660円から使えます。

フリーデスクは月18,700円からです。

02｜ブースとスモールオフィス

一人の席と、チームの部屋

ブースは月48,400円から、スモールオフィスは月148,500円からです。

フリーデスクからブース、スモールオフィスへと、チームの大きさに合わせて移れます。

03｜会議室とイベントスペース

30分からの会議室と、催しの場所

会議室は30分2,200円から、イベントスペースは1時間55,000円からです。

全国の地域と東京をつなぐ催しの舞台になります。

キーワード

DIAGONAL とは

英語で「斜め」を意味する言葉です。DIAGONAL RUN TOKYO の名前に使われています。

縦の組織、横の業界に対して、斜めに交わる。東京と全国、人と企業とアイデアを斜めにつなぐ場所の名前です。

編集部より

東京と全国の地域をつなぐことを、コワーキングの目的に据えています。東京駅から歩ける京橋という場所は、地方から来る人にとって迷わない入口です。

フリーデスクが月18,700円からという料金は、都心の駅近くのコワーキングとしては入りやすい設定です。敷居を下げることが、交わる人の幅を広げます。
