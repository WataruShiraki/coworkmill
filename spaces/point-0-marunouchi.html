丸の内｜コワーキング

point 0 marunouchi｜丸の内2丁目ビル4階、Klein Dytham architecture が内装を手がけた「未来のオフィス空間」

東京駅から歩いて数分、丸ビルの隣の丸の内2丁目ビル4階に、point 0 marunouchi はあります。2019年7月に開いた会員型のコワーキングスペースで、「未来のオフィス空間」を実現するための実証実験の場でもあります。ダイキン、オカムラ、パナソニックなどの企業が参画し、内装のデザインは Klein Dytham architecture が手がけました。2021年1月には、日本のコワーキングオフィスとして初めて WELL認証（WELL v2 pilot）のゴールドランクを取得しています。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

はじめに

オフィスの未来へ

point 0 は「オフィスの未来」を考え続けるための場所です。公式サイトは、オフィスと家、会社と会社、仕事と遊びの境界線が薄くなる時代に、それでも人が集まる「オフィス」の在り方を再定義したい、と書いています。ダイキン、オカムラ、パナソニック、ライオン、TOTO、鹿島、三菱地所など19社が参画し、ここで働く人の動きや環境のデータを集めて、空間の高度化と新しいサービスの創出に取り組んでいます。

求めたのは「丸の内の豊かな緑をそのまま屋内に持ち込んだような、緑あふれる空間」です。その緑の価値を最大にする空気、光、音、香り。妥協のないオフィス家具。シャワーや睡眠など暮らしの要素。豊かな会話を支える飲食。内装は Klein Dytham architecture、植栽は parkERs、ブランディングは Insitu と artless が手がけました。

01｜ワークスペースと緑

様々な植物に囲まれた席

仕事中もリラックスできるよう、様々な植物が置かれています。専用席は14席、自由席は月額会員と15分単位の都度利用があり、どちらも24時間365日使えます。

専用席は12か月契約で月115,500円、自由席の月額会員は12か月契約で月82,500円、都度利用は15分275円（いずれも税込）と公式サイトに載っています。

02｜カフェとコミュニティ

スペシャルティコーヒーと、80名のイベントスペース

施設の中にはスペシャルティコーヒーを提供するカフェがあります。働き方の未来を共に作るためのコミュニティとイベントが豊富だと公式サイトは説明します。

イベントスペースは最大80名を収容します。目的に合わせて使える様々なタイプの会議室もあり、会議室は1時間3,300円、大会議室は1時間6,600円（税込）です。

03｜集中と休息の部屋

メディテーションルーム、集中ブース、ナップルーム、シャワー

メディテーションルームは、瞑想やヨガ、いつもと違う環境で考えを巡らせたいときの部屋です。音と視線を遮るプライベート集中ブースもあります。

作業の効率を高めるための仮眠ブース、24時間使える無料のシャワールーム、無料の低酸素ルームも備わります。働く時間と休む時間を、同じ階の中で行き来できます。

04｜IoTと実証実験

未来のオフィスを体験する

様々なIoT機器が設置されていて、未来のオフィスを体験できます。参画企業の最新の技術やデータ、ノウハウを、オープンスペース、会議室、仮眠ブースに導入しているためです。

ここで働く人の動きや生体の情報、機器の運転データを集めて分析し、空間の高度化と新しいサービスの創出につなげています。座っている人が、そのまま実験の参加者になる場所です。

キーワード

WELL認証とは

空間のデザイン、構築、運用に「人間の健康」の視点を加えた、オフィス空間の評価の仕組みです。アメリカの IWBI が2014年に始め、空気、水、食物、光、運動、温熱環境、音、材料、こころ、コミュニティーの10のコンセプトで評価します。

point 0 marunouchi は2021年1月に WELL v2 pilot のゴールドランクを取得しました。日本のコワーキングオフィスとして初めてのことで、空気・空間のダイキン、家具のオカムラ、照明のパナソニックの3社の技術で実現したと公式サイトは説明しています。

編集部より

空調のダイキン、家具のオカムラ、照明のパナソニックが同じ部屋を作る。ふつうは発注者が別々に選ぶ3つの要素を、作る側が最初から一緒に設計しています。緑あふれる空間という言葉の裏に、この組み方があります。

働く人がそのまま実験の参加者になる、という発想は、内装を「完成品」ではなく「更新し続けるもの」として扱う考え方です。開いてから何年も内装が変わり続けるコワーキングは、そう多くありません。
