新橋｜コワーキング

BasisPoint 新橋銀座口店｜新橋駅銀座口から1分、56名の大会議室まであるコワーキング

JR 新橋駅の銀座口から歩いて1分、カシケイビルの2階に BasisPoint 新橋銀座口店はあります。オープンスペースとソファ席、個室ブース、BOX 席に加えて、会議室が3室、56名が入る大会議室「Lab.」が2室あります。公式サイトに書かれている内容をもとに、この場所の要点をご案内します。

施設 BasisPoint 新橋銀座口店 ↗場所 東京都港区新橋2-19-3 カシケイビル2F交通 JR 新橋駅 銀座口 徒歩1分構成 オープンスペース／ソファ席／個室ブース／BOX席／会議室3室（6・10・12名、B+Cで25名）／大会議室 Lab.A・Lab.B（各56名）営業 平日8:00〜22:00／土日祝10:00〜22:00（年末年始休み）

はじめに

一人の仕事からセミナーまで

新橋銀座口店も「ホテルラウンジのような洗練されたスペース」を掲げる BasisPoint の一店です。高速 Wi-Fi と全席の電源で、テレワークや Web 会議に対応します。

この店の特徴は部屋の大きさの幅です。1名の個室ブースから、25名の結合会議室、56名の大会議室まで、同じ店の中にそろいます。

01｜オープンスペース

駅から1分のラウンジ

オープン席は最初の30分330円、1日の上限3,300円です。月額プランは12,100円から27,500円です。

4名掛けのソファ席もあります。

02｜BOX席と個室ブース

1〜4名で使う席

モニター付きの BOX 席は1〜4名向けで、1時間1,980円です。個室ブースは A・B・C の3室です。

一人で集中する席と、少人数で話す席が分かれています。

03｜会議室

6名から25名まで

会議室は Room.A（6名）、Room.B（10名）、Room.C（12名）の3室です。B と C をつなげると25名で使えます。

商談から社内の会議まで、人数に合わせて部屋を選べます。

04｜大会議室 Lab.

56名が入る2室

大会議室は Lab.A と Lab.B の2室で、それぞれ56名が入ります。

セミナーや勉強会など、大人数の催しにも使えます。

結合会議室けつごうかいぎしつ

キーワード

結合会議室とは

隣り合う2つの会議室の間仕切りを開けて、1つの大きな部屋として使う方式です。BasisPoint 新橋銀座口店では Room.B と Room.C をつなげて25名で使えます。

ふだんは小さな部屋として、必要なときだけ大きな部屋にできます。

編集部より

1名の個室ブースから56名の大会議室まで、一つの店でそろう幅の広さが目を引きます。駅から1分の立地は、人を集める催しに向いています。

ふだんはラウンジで一人で働き、月に一度はここで勉強会を開く。そんな使い方も思い描ける場所です。
