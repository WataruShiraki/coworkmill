How to read this site

Three things we do on every page

Prices in yen, from the source

We list only the prices each space publishes. If a price is not public, we say so instead of guessing.

Address in Japanese, too

Each page shows the address in Japanese — e.g. 東京都渋谷区渋谷3-27-1 — with a copy button and a Google Maps link for taxis.

“Japanese only” when it matters

Booking forms and official websites are often only in Japanese. We tell you before you click.
