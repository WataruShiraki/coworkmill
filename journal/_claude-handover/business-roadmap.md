### Phase 1：本格運用（月10,000クエリ・月10,000-15,000円）

### Phase 2：法人B2B SaaS化（月100,000クエリ・月50,000-150,000円）

## 15. マネタイズ方針確定（2026-05-13）：月額固定MRR重視

### 基本方針

**収益の主軸は「**施設側 + 建築家からの月額固定課金（MRR）**」**とする。 一人運営の安定性・予測可能性・継続性を最優先する設計。

### 7レイヤーの優先順位（再整理）

| Layer | 課金形態 | 優先度 | 位置付け |
|---|---|---|---|
| **L1 施設掲載課金（Free/Standard/Pro）** | **月額固定** | ★★★ 最優先 | 主力MRR |
| **L2 建築家ポートフォリオ** | **月額固定** | ★★★ 最優先 | 差別化MRR・最有望 |
| L3 法人B2B SaaS | 月額固定 | ★★ 重要 | 中期最大MRR・年単位契約 |
| L4 成約手数料 | 従量 | ★ 補助 | 「業界最安5-10%」の正義の旗・MRR補完 |
| L5 編集メディア（PR記事・スポンサー） | 単発 | ★ 副次 | ブランディング兼収益 |
| L6 データ・コンサル | 単発 | ☆ 長期 | 不定期・ハイマージン |
| L7 イベント・アワード | 単発 | ☆ 長期 | ブランド強化兼収益 |

### MRRを軸にする理由

| 理由 | 内容 |
|---|---|
| **予測可能性** | 一人運営でキャッシュフロー予測が立てやすい |
| **継続性** | 単発スポンサーや成約手数料は波が大きく不安定 |
| **スケール** | 媒体追加時に「既存MRR」が下支えになる |
| **資金調達不要** | 月額継続収入があれば借入・出資なしで成長可能 |
| **業務委託化の判断基準** | MRRが一定額超えたら編集者を業務委託、 などの意思決定が明確 |

### 課金プラン設計（COWORKMILL基準）

#### 施設側（L1）
| プラン | 月額 | 機能 |
|---|---|---|
| **Free** | 0円 | 基本情報のみ・1施設 |
| **Standard** | **¥3,000-5,000** | 写真5枚追加、 問合せ受付、 5施設まで、 上位表示 |
| **Pro** | **¥10,000-15,000** | PICK badge、 最上位表示、 建築家紐付け、 写真無制限 |

**例え話**: 食べログの「お店パートナー」プランと同じ構造。 ただし飲食業界より単価高めに設定可能（B2B寄りのため）。

#### 建築家側（L2）
| プラン | 月額 | 機能 |
|---|---|---|
| **Free** | 0円 | 基本プロフィール・作品3件まで |
| **Standard** | **¥5,000-10,000** | 作品10件、 ポートフォリオページ、 問合せフォーム |
| **Pro** | **¥15,000-30,000** | 作品無制限、 トップページ露出、 案件マッチング優先表示 |

**例え話**: SUUMOの「注文住宅カタログ」のような構造。 建築家側にとっては**クライアント獲得チャネル**として月額1〜3万円は十分元が取れる投資。

### MRR目標推移

| 時期 | 施設側MRR | 建築家MRR | 合計MRR | 備考 |
|---|---|---|---|---|
| 6ヶ月後 | 30施設×¥4,000 = ¥120,000 | 10事務所×¥8,000 = ¥80,000 | **¥200,000** | 立ち上げ期 |
| 12ヶ月後 | 100施設×¥4,000 = ¥400,000 | 30事務所×¥10,000 = ¥300,000 | **¥700,000** | 軌道に乗る段階 |
| 24ヶ月後 | 300施設×¥4,500 = ¥1,350,000 | 100事務所×¥12,000 = ¥1,200,000 | **¥2,550,000** | 主力収益化 |
| 36ヶ月後 | 600施設×¥5,000 = ¥3,000,000 | 200事務所×¥15,000 = ¥3,000,000 | **¥6,000,000** | スケール期 |

### 営業フローの優先順位

1. **無断登録 → オーナー認証申請** を受けたら、 まず**Free認証完了**まで誘導
2. Free認証後、 利用状況を見て **Standard案内**（写真追加・問合せ受付の価値訴求）
3. Standard利用が3〜6ヶ月続いたら **Pro案内**（PICK badge・建築家紐付け）
4. 建築家には「**自分の作品集として登録**」をフックに、 別途Standard〜Pro案内

### 重要原則

- **成約手数料での消耗戦をしない**。 既存ポータルが30%手数料で施設に嫌われている構図を反面教師に。
- **L4成約手数料は「業界最安5-10%」を明示** してMRRプランの付加価値として位置付ける。
- **単発スポンサー収入に依存しない**。 編集メディア収入はL5として副次的に位置付け、 メインはあくまでMRR。

## 比較ショック・ループ戦略（2026/05/13 確定）

### コア思想

COWORKMILL の無料Tier2施設は「あえてスカスカに見せる」ことでオーナーの参加動機を作る。 退会後もSEOは維持され、 中身がスカスカで晒されるという「アイデンティティ防衛」心理を活用してロックインする。

### カスタマージャーニー（オーナー側視点）

```
① ジャーナル記事で発見（Instagram埋め込み + 「詳しくはCOWORKMILLで」リンク）
   ↓
② 施設詳細ページ（Tier 2）に到着 → スカスカ
   ↓
③ ページ下部「同じエリアのおすすめ」「同じ最寄駅のおすすめ」発見
   ↓
④ 他施設（Tier 1）の有料ページを見て比較ショック
   ↓
⑤ 自分のページに戻る → 寂しさを実感（アイデンティティ防衛）
   ↓
⑥ オーナーバナーから認証申請
   ↓
⑦ Free → Standard → Pro へアップグレード
```

### 役割分担（3階層）

| 場 | 役割 | 画像・Instagram |
|---|---|---|
| ジャーナル記事 | 編集メディア・流入元 | ⭐ Instagram埋め込み多用 |
| 施設詳細（無料 Tier 2） | 名簿・受付窓口 | ❌ 空っぽ（プレースホルダー表示） |
| 施設詳細（有料 Tier 1） | 完成ショールーム | ⭐ オーナー登録画像 |

### 重要な決定事項

1. **無料 Tier 2 でも SEO は最高水準で維持**（順位を下げない）
   - 「目立つのに中身が空っぽ」のギャップで参加動機を作る
2. **無料 Tier 2 は「未登録」プレースホルダーを目立たせる**
   - 「📷 写真は未登録です / オーナー様による登録をお待ちしています」
   - 「💬 まだ口コミがありません」など
3. **Instagram埋め込みは ジャーナル記事限定 で使用**（無料Tier2施設からは外す）
4. **Google Places API は使わない**（2025/02 から無料枠撤廃・最低 $275/月）
5. **退会時の脅し文句から「SEO低下」を外す**
   - 主軸は「中身がスカスカで晒され続けます」

### 比較ショック・ループのレコメンド軸（Phase A 実装）

優先順位順：

| 軸 | セクション名 | 条件 | データ要件 |
|---|---|---|---|
| 🥇 最寄駅 | 「同じ最寄駅のおすすめ」 | nearest_station 一致 + plan!=free | spaces.nearest_station |
| 🥈 エリア | 「同じエリアのおすすめ」 | area 一致 + plan!=free | spaces.area |

**却下した軸**：
- 同じ建築家：データがまだ揃わない
- 同じ雰囲気タグ：無断掲載では取得できない
- PICK施設：別エリアでは関連性が低い

### ロックイン要素の優先順位

1. **蓄積された利用者の声**（最重要・航さん指定）
2. 登録写真・営業時間・料金プラン
3. アクセス解析データ
4. 連携建築家・ジャーナル取材記事の詳細リンク
5. お気に入り登録者への通知

### 退会画面の設計方針

- 「失う具体的なもの」を列挙
- 「住所と施設名は残るので、 中身がスカスカで晒され続けます」と明示（SEO低下は使わない）
- ダウングレード（Pro → Standard）の選択肢を提示
