## COWORKMILL 公開戦略（2026-05-21 確定）

公開は段階方式で進める。

1. **サンプルサイト化** — まずダミー（サンプル）施設データを多数投入し、サンプルサイトとして仕上げる。これを営業ツールとして使う。
2. **正式公開の条件** — 口頭で約10施設の掲載を口説けた時点で正式公開する。それまでは本公開しない。

**TOPページ構成**：coworkmill-top-prototype.html で確定（11ブロック）。ヒーロー → 選定基準 → 建築家から探す → PICK UP「今月の一軒」 → 仕事タイプで探す → 新着の施設 → 棚エリア（Netflix型）→ 23の切り口から探す → ジャーナル → 地域から探す → フッター。棚は tags.show_on_shelf と shelf_min_count により、対象施設が一定数集まると自動表示される。

**Stripe**：本番設定（env / Product / Webhook / Functions）は完了済み。本番初決済テストは正式公開の直前まで保留。
