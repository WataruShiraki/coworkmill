BASIS POINT SHIMBASHI

カフェのような、大人のホテルラウンジ

Conclusion

新橋・虎ノ門は、24時間動く街どの拠点を選ぶかは、あなたのリズム次第

10施設中5施設が24時間営業――この数字は、新橋・虎ノ門というエリアの「働く時間に制約がない」という特性を物語っている。終電を逃した夜の続き、始発前のメール、深夜のコード書き、休日のひとり籠もり。どんなリズムにも、フィットする拠点がきっと見つかる。

駅前で朝6時から動きたいならビステーション新橋。落ち着いたカフェ風の集中環境ならBasis Point 新橋店。完全にマイペースに使うならTHE CODE 新橋かリージャス系。眺望付きで品の良い席ならCozy Works 城山トラストタワー。

働く場所が選べる時代の、新橋・虎ノ門の地図がこれだ。
