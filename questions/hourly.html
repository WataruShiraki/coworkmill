1時間から使えるコワーキングは？

1時間単位のドロップインを用意している施設があります。DIAGONAL RUN TOKYO は平日1時間660円、.andwork 麻布十番は1時間800円、.andwork 渋谷は1時間1,100円です。

目次

  1. 平日は1時間660円
  2. 1時間800円、10回券もある
  3. 1時間1,100円、ドロップインは24時まで
  4. 昼のポップイン 1日2,200円

01｜DIAGONAL RUN TOKYO（京橋）

平日は1時間660円

DIAGONAL RUN TOKYO は、平日なら1時間660円で使えます。1日は3,300円です。

東京と全国各地の人と企業とアイデアが、斜めに交わる場所を掲げています。

02｜.andwork 麻布十番（麻布十番）

1時間800円、10回券もある

.andwork 麻布十番は、1時間800円、1日2,500円です。10回券は17,500円です。

営業は8時から22時までです。

続きを読む →

03｜.andwork 渋谷（渋谷）

1時間1,100円、ドロップインは24時まで

.andwork 渋谷は、1時間1,100円、1日3,300円です。

ドロップインは7時から24時まで使えます。

04｜MIDORI.so Nihonbashi（東日本橋）

昼のポップイン 1日2,200円

MIDORI.so Nihonbashi は、昼のポップインが1日2,200円です。入会金と会費はありません。

夜は1泊8,800円で、同じ建物に泊まれます。
