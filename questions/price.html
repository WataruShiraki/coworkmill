コワーキングの月額料金は、どのくらい？

共用の席を使うプランは、月1万円台から6万円台まで幅があります。SAAI のフリーデスクは月33,000円、MIDORI.so のフリーデスクは月42,350円からです。

  4. 1拠点プラン 月8,800円

01｜有楽町 SAAI Wonder Working Community（有楽町）

コミュニティ 月16,500円から

有楽町 SAAI は、コミュニティ会員が月16,500円、フリーデスクが月33,000円、固定ブースが月77,000円です。

新東京ビルの地下1階、1階、4階を使う事業創造のコミュニティです。

02｜MIDORI.so Nakameguro（目黒）

フリーデスク 月42,350円、固定デスク 月60,500円

MIDORI.so Nakameguro は、フリーデスクが月42,350円、固定デスクが月60,500円です。入会金は11,000円です。

蔦に覆われた廃屋を改装した、本館と母屋の2棟のシェアオフィスです。

03｜DIAGONAL RUN TOKYO（京橋）

フリーデスク 月18,700円から

DIAGONAL RUN TOKYO は、フリーデスクが月18,700円からです。ドロップインは1日3,300円、平日は1時間660円でも使えます。

京橋MIDビルの4階にあり、宝町駅から歩いて約1分です。

04｜THE HUB 日本橋大伝馬町（日本橋）

1拠点プラン 月8,800円

THE HUB 日本橋大伝馬町は、1拠点プランが月8,800円です。個室のレンタルオフィスは月45,100円からです。

有人フロントのある、全81室の個室オフィスです。
